## 图纸清单

覆盖工艺流程：**取水 — 混凝 — 沉淀 — 过滤 — 消毒 — 供水**

## 制图说明

- 图层分设、线宽分级、尺寸与标高标注按制图规范执行
- 参照 GB50013-2018《室外给水设计标准》出图要求
- 所有图纸提供 DWG 原图下载，可用 AutoCAD / 天正给排水直接打开
